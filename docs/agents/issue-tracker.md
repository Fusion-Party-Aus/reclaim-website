# Issue tracker: GitHub

Issues and specs live in `Fusion-Party-Aus/reclaim-website`. Always pass `--repo Fusion-Party-Aus/reclaim-website` to `gh issue`, `gh label`, and `gh pr` commands; the origin remote points to a different repository.

Read: `gh issue view <number> --repo Fusion-Party-Aus/reclaim-website`.
List: `gh issue list --repo Fusion-Party-Aus/reclaim-website`.
Create: use `gh issue create --repo Fusion-Party-Aus/reclaim-website --title "..." --body-file <file>` for exact multiline text.

PRs as a request surface: no.
