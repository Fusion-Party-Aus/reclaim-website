## Crop and delivery

Central square previews preserve the kookaburra's face, memory chips, forest canopy, resting swan and sunlight; these fit the concept's circular crop. Keep `object-fit: cover` with a centred subject as the starting point. The long diagonal memory module loses its extreme ends within a circle but the chips remain legible. Equity is a landscape scene rather than a portrait: its circle should retain homes and central shared green space. Do not claim its public accessibility or fairness outcomes from the photograph alone.

A delivery URL can append `?auto=format&fit=crop&w=320&h=320&q=75` to each verified source path. Request appropriately sized variants, set explicit square dimensions and lazy-load values images below the hero. Preserve visible compact photo credits linked to the exact photo pages, grouped below the values row if individual credits would crowd small circles. Alt may be empty when the image is purely decorative and the adjacent value text fully communicates the content; the table provides accurate subject descriptions if meaningful alt is desired.
